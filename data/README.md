# Private data directory

The patient-level Excel workbook is intentionally **not included in the GitHub repository**.

For local reproduction, the private workbook is placed at:

`data/patient_analysis_workbook.xlsx`

The `.gitignore` file prevents Excel/CSV patient-level files in this directory from being committed.

Before transferring the patient-level workbook to another person or institution, confirm that the applicable research, ethics, institutional, and data-sharing requirements permit the transfer.
